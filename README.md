## 🌐 របៀបបង្ហោះហាងឡើង Online ដោយឥតគិតថ្លៃ (Free 100%)

ដើម្បីឱ្យហាងរបស់អ្នកអាចបើកលើ Telegram លើទូរស័ព្ទបាន អ្នកត្រូវមាន Link HTTPS (ឧទាហរណ៍ `https://sreyleak-shop.vercel.app`)៖

### ជម្រើសទី ១: ប្រើ Vercel (ងាយស្រួលបំផុត - ១ នាទី)
1. ចូលទៅកាន់ [vercel.com](https://vercel.com) រួច Sign Up ដោយឥតគិតថ្លៃ
2. Drag & Drop ថត `TG minishop` នេះចូល Vercel ឬ Push ទៅ GitHub រួច Import ចូល Vercel
3. អ្នកនឹងទទួលបាន Link HTTPS មួយភ្លាម (ឧ. `https://sreyleak-cosmetics.vercel.app`)

### ជម្រើសទី ២: ប្រើ GitHub Pages
1. បង្កើត Repository មួយនៅលើ GitHub រួច Upload ឯកសារទាំងអស់ចូល
2. ចូលទៅកាន់ **Settings** -> **Pages**
3. ត្រង់ **Branch** រើសយក `main` ហើយចុច **Save**
4. អ្នកនឹងទទួលបាន Link ឧ. `https://username.github.io/repository-name/`
